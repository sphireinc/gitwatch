# Default Keymap

| Key | Action |
|---|---|
| ↑/↓, j/k | Move selection |
| PgUp/PgDn | Page |
| gg / G | Top / bottom |
| Space | Stage or unstage selected path |
| a | Stage all |
| U | Unstage all |
| d | Open diff |
| 1 | Status view |
| b | Branches view |
| s | Stashes view |
| l | History view |
| c | Commit workspace |
| Ctrl-S | Execute a valid commit |
| Tab | Cycle focus/panes |
| / | Filter |
| r | Force refresh |
| ? | Help |
| Esc | Close overlay / cancel |
| q | Quit |

Destructive actions must use deliberately distinct bindings and confirmation dialogs.
